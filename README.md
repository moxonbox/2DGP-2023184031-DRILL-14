# DRILL 14: 새떼 비행

## 프로젝트 구조

- `main.py`: 1600×600 캔버스를 열고 게임을 실행한다.
- `game_framework.py`: 모드 수명주기와 초 단위 `frame_time`을 관리한다.
- `play_mode.py`: 입력을 처리하고 장면을 구성한다.
- `game_world.py`: 레이어별 개체를 갱신하고 그린다.
- `boy.py`, `ball.py`, `grass.py`: 기존 캐릭터, 공, 배경이다.
- `brid.py`: 새 개체와 새떼의 애니메이션·물리를 담당한다.

## 구현 기준

`PRD.md`에 따라 `bird_animation.png`를 사용하는 새 10마리가 좌우로
반복 비행한다. 기존 캐릭터와 입력은 유지한다. 시간 기반 날갯짓,
관성 있는 방향 전환, 비행 힘, 이웃 간 군집 규칙을 구현한다.

작업은 20개 커밋으로 나누고, 제목은 `001_명세_상세 내용`처럼
세 자리 번호와 두 글자 주요 내용으로 기록한다. 마지막 커밋 본문에
물리 모델의 논리와 검증 결과를 남긴다.
